# OrderFix avatar

`orderfix.svg` is an original, code-authored vector icon made from simple geometric paths. It uses no external images, fonts, personal photos, or stock assets. The shopping bag represents an order; the check badge represents a verified action.

`orderfix.png` is the 512 × 512 raster version, rendered from the SVG with Sharp. The rounded-square corners remain transparent. Use the PNG as the Agentverse profile avatar and the SVG where vector graphics are supported.

Palette: dark teal `#073F42`, warm white `#FFF9EE`, coral `#F38D73`.
